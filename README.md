# java-calculator
Ein einfacher Rechner, der in Java geschrieben wurde. Unterstützt grundlegende Operationen wie Addition, Subtraktion, Multiplikation, Division und Modulus.

✨ Mit der Zeit werde ich ihn verbessern, sodass er auch quadratische und logarithmische Gleichungen lösen kann. 🛠️

Anforderungen

Java Development Kit (JDK) 21 oder höher.
